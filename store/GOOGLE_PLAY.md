## Безопасность данных (рекомендуемые ответы)

В игре нет аккаунтов, рекламы, аналитики и сторонних SDK. Онлайн-режим отправляет на сервер ник, выбранного героя и ходы. Сервер держит их в памяти и удаляет через 30 минут после ухода всех игроков.

- Собирает ли приложение данные: **Да**.
  - Личная информация → **Имя** (ник за столом): собирается, не передаётся третьим лицам, необязательно (только для онлайн-игры), цель — **функции приложения**.
  - Действия в приложении → **Взаимодействие с приложением** (ходы в онлайн-партии): то же самое.
- Данные шифруются при передаче: **Да** (HTTPS/WSS).
- Можно ли запросить удаление: данные удаляются автоматически. Если форма требует способ запроса, укажите «Нет».

## Порядок публикации

1. Аккаунт разработчика: play.google.com/console, разовый взнос **$25**, подтверждение личности.
2. «Создать приложение»: название «108 — карточная игра», язык — русский, игра, бесплатная.
3. Заполнить «Контент приложения» (политика, реклама, доступ, аудитория, безопасность данных, рейтинг) и «Основную информацию» (тексты, значок, обложка, скриншоты).
4. **Подпись приложения Google Play** включится сама при первой загрузке: Google хранит ключ подписи, вы — только ключ загрузки.
5. **Закрытое тестирование**: создать трек, добавить **не меньше 12 тестировщиков** (адреса Gmail или группа Google), загрузить `108-1.0.0-1.aab`, отправить на проверку. Тестировщики переходят по ссылке «Стать тестировщиком» и устанавливают игру из Google Play.
6. Через **14 дней** непрерывного участия тех же 12+ тестировщиков — «Запросить доступ к рабочей версии» на панели. Это правило для личных аккаунтов, созданных после 13.11.2023.
7. После одобрения — выпуск в «Рабочую версию».

## Как выпускать обновления

1. Поднять `versionCode` (например, 2) и `versionName` в `android/app/build.gradle`, отправить в GitHub.
2. GitHub Actions соберёт `108-unsigned.aab` в релизе `android-latest` (и журнал в `android-log`).
3. Подписать ключом загрузки:
   `jarsigner -keystore upload-keystore.p12 -storetype PKCS12 -sigalg SHA256withRSA -digestalg SHA-256 -signedjar 108-1.0.1-2.aab 108-unsigned.aab upload`
4. Загрузить новый AAB в нужный трек.

## Ключ загрузки — беречь

`android-keys/upload-keystore.p12` и пароль из `android-keys/ПАРОЛЬ.txt` нужны для каждого обновления. Сделайте резервную копию (флешка, менеджер паролей) и никому не отправляйте. В GitHub их нет и не должно быть. Если ключ потеряется, через Play Console можно запросить сброс ключа загрузки: так как ключ подписи хранит Google, приложение не пропадёт.
